# 未·央 · 曲江沉月案 / 真人双人联机版

两位真人各操作自己的角色：巡捕与幻术师。选定身份后，全程固定。分头调查、独立阅读、分别收集线索；共同节点由双方到场、各自提交与共同操作推动。

## 公网分享版

新增 Sites 云端房间服务。玩家打开公开网页，选择身份并创建房间，复制邀请链接给搭档即可；不需要下载、安装、注册账户或保持房主电脑运行服务器。

云端使用 D1 保存七天内的房间，通过版本条件更新保护双方同时操作，并为请求去重。玩家凭证仅保留在自己的标签页；刷新可重连。保留原有本地联机入口。

当前使用 Sites 公测包含在现有套餐内的额度，没有购买服务器、域名或额外容量；额度受平台限制，不能承诺永久免费或无限流量。

构建公网版本：`npm ci` 后运行 `npm run build`。`dist/` 为发布产物，原画在源项目中保留，线上图片压缩为带透明通道的 WebP。`npm run test:cloud` 验证编译后的云端接口（测试运行器需要 Node.js 24）。

## 开始游玩（本地版）

### macOS

双击项目中的 **启动联机.command**。保持打开的终端窗口运行；游戏会打开 `http://localhost:8787`。需 Node.js 18 或更新版本；启动器也能使用这台电脑已有的 Codex Node 运行环境。

1. 房主选择巡捕或幻术师，点击「创建双人房间」。
2. 将等候页面上的邀请地址发给搭档。房主与搭档连接同一 Wi-Fi 时，可直接使用显示的局域网地址。
3. 搭档选择另一个角色，输入六位房间码加入。两人到齐后分别进入自己的开场。
4. 也可在同一台电脑的两个独立浏览器/标签页进行双人测试。不要复制已有房间的标签页后冒充另一人；新开游戏首页加入即可。

### Windows / Linux / 通用启动

在项目目录运行：

```sh
node server.cjs
```

或 `npm start`。无需安装任何第三方运行依赖。Windows 可双击 `启动联机.bat`。

**联机版需要运行随附的房间服务，不能仅以 file:// 打开 index.html 游玩，也不能仅部署到 GitHub Pages。** 本地入口提供本机与局域网联机；公网分享使用新增的 Sites 云端入口，不依赖本地服务。

服务支持 `PORT` 环境变量。提供 Dockerfile 用于部署。公网代理需支持持续 HTTP 流、关闭 SSE 缓冲、启用 HTTPS，并只运行一个实例或使用同一有状态进程；这版不是多实例集群服务。

## 固定身份与双人玩法

- 巡捕从大理寺接到报案信；幻术师从幻术院追查未申报的船舱机关。
- 双方各自阅读，不需要同时点击每句对话。共同剧情的末尾等待两人完成。
- 分头调查时不能查看搭档的私人案卷，也不能操纵搭档的选择。
- 巡捕委托调查影响幻术师能否追加反光信号；幻术师分享结构图影响巡捕追问与救援选项。
- 会合时，每位真人只从自己的记录中提交一项证据，系统核对两项是否相互解释。
- 水舱与追逐 QTE 均需两人准备。巡捕支撑配重、救援与追捕；幻术师转轮、解绳与引导。双方各有三步动作，各自至少成功两步才判共同成功。
- QTE 是联机共同事件，切离页面、打开设置不会暂停。可提前在设置中启用舒缓模式。失败仍可推进剧情。
- 结案时双方独立选择嫌疑人、手法和动机。意见不同时显示搭档提交的判断，重新核对后提交；一致才结案。
- 关键条件保留：EVIDENCE ≥ 6 且有门闩、铜轮才能完整复原机关；账目动机需要账页；TRUTH ≥ 15 显示更明显倒影异常。
- 默认隐藏数值，设置中可显示 TA、TB、TRUTH、DREAM、CHAOS、EVIDENCE。

## 美术与地图

- `assets/cutouts/`：12 张真正包含 Alpha 透明通道的角色图（5 张原立绘、7 张动作）。原画保留，抠图后采用正常叠加，不再通过 screen 混合隐藏背景。
- `assets/layers/`：12 处地图建筑/船只的透明原画切片，按屋檐、塔身、船身轮廓裁切；部分亭台开口单独挖空。
- `assets/map-ground.png`：修补后的底图，建筑抬起时不会在原位置留下第二个相同建筑。
- `layers.js`：图层定位与对应轮廓判定路径。悬停和键盘聚焦使独立图层浮起，光晕跟随透明边缘。
- `assets/scenes/`：14 张场景原画。船舱、水舱全屏横向环视，物件名称不会提前展示。
- 人物使用独立前景层、投影和动作动画；没有将半身立绘改成 3D 模型。

## 进度与重连

房间服务在每次有效操作后保存到 `.rooms/`，重启时恢复最近七天的房间。该目录不提交到仓库或包含在发行压缩包中。

身份凭证存放在当前标签页的 sessionStorage；刷新该标签页会自动重连，断线后自动尝试恢复。请保留原标签页。清除浏览器会话或主动离开后，无法仅凭房间码夺回已占用角色；可创建新房间。身份不能在原房间切换。关闭服务器会使双方断线。

## 验证

```sh
npm test
```

测试包括：两种关键选择 × QTE 成功/失败的四条完整双人路径；角色权限、私人线索、错误互证、重复奖励；房间恢复；两套独立 HTTP 凭证、实时事件流及重连；所有游戏页面与面板的渲染结构。最终视觉与操作手感仍需在两台真实设备上游玩检查。

## 项目结构

- `index.html` / `style.css` / `script.js`：界面、联网、拖动调查和动作画面。
- `data.js` / `core.js`：剧情、线索坐标与规则。
- `multiplayer.cjs`：服务端固定身份、私有记录、双方会合与共同判定。
- `server.cjs`：无第三方运行依赖的静态服务、房间、实时事件与存档。
- `tests/multiplayer.test.cjs`：完整双人流程和网络集成测试。
- `assets/generation-prompts.json`：此前原创素材生成记录；本次抠图按用户授权采用程序分割和手工轮廓修整，未重新生成角色。
