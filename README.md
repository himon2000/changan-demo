# 《长安未醒：曲江沉月案》网页 Demo

双击 `index.html` 即可在浏览器中打开。项目是纯 HTML、CSS、JavaScript，图片均在 `assets/`，不需要网络或后端。

## 游玩路线

开始界面 → 双人说明 → 曲江地图 → 诗会与尸体 → 船舱环视 → 船娘及崔绰问询 → 地图自由调查 → 水舱环视 → 水舱 QTE → 追凶 QTE → 推理指认 → 倒影结尾。

地图的主要地点包括曲江池、诗会画舫、杏园、大理寺、幻术院、东市入口；次要地点包括酒肆、旧船坞、香料摊、诗社书坊、岸边祠亭、钟楼。支线证据可提高推理精度，主线至少调查一处船舱线索和水舱铜轮。

## 操作

- 地图：点击地点。
- 环绕调查：拖动鼠标或手指左右转动，也可用左右箭头或画面下方按钮；点击发光热点。
- QTE：按提示的 A、D、W 键，或点击操作按钮。失误会改变数值，但不会使游戏卡住。
- 界面上方可打开证据簿和数值面板，也可切换数值标注显示。

## 分支条件

- 初始数值：TA 50、TB 50、TRUTH 5、DREAM 65、CHAOS 0、EVIDENCE 0。
- A 在开场信任 B，且 TA ≥ 55，B 才可在问询中主动拆开灯座并分享发现。
- B 选择让 A 核对证词，会开放 A 的特殊追问论证；选择分享灯座线索，则开放相应机关论证。
- EVIDENCE ≥ 6 且持有门闩、铜轮线索，才可选择精确复原密室。
- TRUTH ≥ 15 时，结尾水中楼阁的异常更明显。
- QTE 成功次数、救援或追凶的选择会改变证据、信任和失稳值。

本 Demo 用同屏轮流决策演示双人因果玩法；未实现网络联机与存档。
