# 长安未醒 · 曲江沉月案 / 双影版

直接用浏览器打开 `index.html`。纯 HTML / CSS / JavaScript，所有图片随项目附带，无需安装、账户、网络或后端。

## 这次更新

- 主角不展示个人姓名，只称「巡捕」「幻术师」。开始画面直接选择身份。
- 两人拥有不同开场、调查任务、物件解读与个人案卷。巡捕追查现场和证词，幻术师检查门闩与结构。地图中可以切换角色。
- 地图移除可见地名和按钮标签。12 处建筑、画舫与水域使用与原画对应的多边形点击区域；悬停或键盘聚焦时，对应图像单独浮起、显现金色边缘。
- 新增 14 张场景背景：画舫、船舱、水舱、大理寺、幻术院、东市、杏园、酒肆、旧船坞、书坊、祠亭、更鼓楼、香料摊、曲江池。
- 保留原有人物外形，新增 7 张动作立绘：巡捕查杯与救援、幻术师验镜与拉绳、主持防备、船娘指路、诗人执笔。
- 船舱与水舱使用全屏、3:1 横向全景绘图。线索嵌在真实场景中，点击物件实际所在范围即记录，不显示预先命名的标记。调查成功后可查看物件局部图和当前角色的观察；名称仅收录在案卷里。
- 两段 QTE 包含摇船、涨水、摆绳、动作立绘、追逐镜头和命中反馈。先确认准备，再开始计时。支持触屏按钮和舒缓模式，离开页面或打开面板时暂停。
- 地图与结尾自动保存到当前浏览器。刷新后可从开始界面继续。

## 流程与互相影响

选择身份 → 独立开场 → 诗会命案 → 两人分头调查 → 各自查验船舱 → 巡捕问船娘 / 幻术师核旧图 → 回画舫选择双方证据验证 → 水舱调查 → 灌水 QTE → 救援或追凶 → 追逐 QTE → 人物、手法、动机三步推理 → 条件结尾。

同一设备轮流操作两位角色。当前不是网络联机版本，角色选择也不是账户登录。

- 巡捕委托机关调查，会增加信任，并允许幻术师在 TA ≥ 55 时附上反光验证方法。
- 幻术师分享旧图，开放巡捕的换灯追问与踩配重救援选项。若先走幻术师线路，巡捕后续问询会直接出现追加对白。
- 巡捕安抚船娘，她会指出水舱检修通道；严格询问则补强时间证据。
- 两人分别完成任务后，必须用现场物理痕迹与门闩机关记录互相验证。
- 巡捕选择顶门或踩配重，会改变下一段幻术师 QTE 的动作序列。
- 追逐 QTE 随起始角色改变：巡捕执行追捕，幻术师执行折光、投绳与配重支援。
- EVIDENCE ≥ 6，且拥有门闩、铜轮记录，才开放完整机关复原；账目动机需要找到对应账页。
- TRUTH ≥ 15，结尾的倒影异常更明显。TA / TB 仍为双向信任，DREAM 为依恋，CHAOS 为失稳。
- 同一物件、重复走访均不会重复累计数值。

## 操作

- 地图：鼠标悬停建筑再点击；触屏直接点击；键盘 Tab 选择建筑、Enter 进入。
- 调查：按住画面左右拖动；点击物件；也可用左右箭头或底部滑杆环视。Tab 聚焦物件提供键盘替代操作。
- QTE：按提示的 A / D / W 或点击按钮。每次操作独立判定，失败仍可推进。
- 设置：默认隐藏数值；开启「显示开发数值」查看选项变化和当前状态。可延长 QTE 操作时间。

## 文件

- `index.html`：入口。
- `data.js`：角色、地图轮廓、场景及物件判定范围（归一化坐标）。
- `core.js`：双人剧情、分支条件、数值、证据与结局。
- `script.js`：页面渲染、环视拖动、物件点击、QTE 时钟与本地保存。
- `style.css`：界面、光边、画面动作、响应式布局与减少动态效果支持。
- `assets/scenes/`、`assets/poses/`：新增原创背景与动作图。
- `assets/generation-prompts.json`：内置 imagegen 的生成提示记录。
- `tests/core.test.cjs`：独立于浏览器的流程与渲染结构检查。
